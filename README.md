# Putar: website dan unduhan

**Putar** adalah pemutar video dan audio freeware untuk Windows. mpv dan FFmpeg sudah ada di dalamnya,
bilah kontrolnya selalu terlihat di bawah gambar, dan tidak ada iklan.

- Website: https://romyrudiansah.github.io/putar/
- Unduh installer: https://romyrudiansah.github.io/putar/#unduh
- **Diskusi, tanya jawab, ide, laporan masalah:** tab [Discussions](https://github.com/romyrudiansah/putar/discussions)
- Kebijakan privasi: https://romyrudiansah.github.io/putar/privacy.html

Repo ini hanya berisi hasil build website, dan installernya ada di
[Releases](https://github.com/romyrudiansah/putar/releases). Putar adalah freeware dan kode sumbernya tidak
publik. Lisensinya ada di [LICENSE.txt](LICENSE.txt), dan komponen pihak ketiga beserta alamat sumbernya ada
di [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Isi repo ini ditimpa setiap rilis.

**Putar** is a freeware video and audio player for Windows. This repository only holds the built website,
and the installer is under [Releases](https://github.com/romyrudiansah/putar/releases). Putar's own source
code is not public; third-party components and their source locations are listed in
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Questions, ideas, and bug reports go to
[Discussions](https://github.com/romyrudiansah/putar/discussions). Contact: romy.rudiansah@gmail.com
