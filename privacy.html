Kebijakan privasiPrivacy policy

Terakhir diperbarui: 9 November 2026Last updated: 9 November 2026

Putar adalah pemutar video dan audio untuk Windows.Putar is a video and audio player for Windows.

Data yang disimpan aplikasiWhat the app stores

Putar menyimpan pengaturan, riwayat putar, playlist terakhir, penanda, dan laporan galat di %APPDATA%\Putar di komputer Anda. Riwayat berisi lokasi atau alamat yang Anda putar, judul, durasi, dan posisi terakhirnya. Anda bisa menghapus riwayat di Pengaturan → Riwayat, dan uninstaller juga menawarkan untuk menghapus folder itu. Pustaka hanya membaca nama file di folder yang Anda pilih, dan hasilnya tidak disimpan. Kunci API OpenSubtitles, bila Anda mengisinya, tersimpan di pengaturan sebagai teks biasa.Putar keeps its settings, playback history, last playlist, bookmarks, and error reports in %APPDATA%\Putar on your computer. The history holds the path or address of what you played, its title, length, and last position. You can delete the history in Settings → History, and the uninstaller offers to delete that folder too. The library only reads file names in the folders you choose, and the result is not saved. Your OpenSubtitles API key, if you enter one, is stored in the settings as plain text.

Tangkapan layar yang Anda ambil masuk ke folder pilihan Anda, bawaannya Gambar\Putar.Screenshots you take go to the folder you choose, by default Pictures\Putar.

Sambungan internet aplikasiWhat the app connects to

Putar tersambung ke internet dalam empat keadaan, dan tidak mengirim data pemakaian ke pengembang:Putar connects to the internet in four cases, and it sends no usage data to the developer:

  • Saat Anda membuka alamat internet. Bila yt-dlp terpasang dan alamat itu bukan file langsung, yt-dlp ikut menghubungi situs tersebut.When you open an internet address. If yt-dlp is installed and the address is not a direct file, yt-dlp contacts that site too.
  • Sekali sehari untuk memeriksa versi baru, dengan meminta latest.json dari situs Putar di GitHub Pages. Tidak ada data Anda di dalam permintaan itu, dan pemeriksaan ini bisa dimatikan di Pengaturan → Pembaruan. Installer baru diunduh dari GitHub hanya bila Anda setuju.Once a day to check for a new version, by requesting latest.json from the Putar website on GitHub Pages. That request carries none of your data, and you can turn the check off in Settings → Updates. A new installer is downloaded from GitHub only if you agree.
  • Saat Anda menekan Cari di dialog subtitle online. Kata pencarian, hash file, bahasa, dan kunci API Anda dikirim ke OpenSubtitles dan mengikuti kebijakan privasi mereka.When you press Search in the online subtitle dialog. The search words, a file hash, the languages, and your API key are sent to OpenSubtitles and fall under their privacy policy.
  • Saat Anda menekan Pasang yt-dlp, untuk mengunduhnya dari GitHub.When you press Install yt-dlp, to download it from GitHub.

Laporan galat ditulis hanya ke komputer Anda dan tidak dikirim ke mana pun. Anda sendiri yang memutuskan apakah menyalinnya ke Komunitas.Error reports are written only to your computer and are not sent anywhere. You decide whether to copy one to the Community.

Yang tidak kami lakukanWhat we do not do

  • Tidak ada analitik, telemetri, iklan, atau pelacakan.No analytics, telemetry, advertising, or tracking.
  • Tidak ada akun, dan tidak ada data yang dijual atau dibagikan.No accounts, and no data sold or shared.

Situs Putar juga tidak memakai cookie, analitik, atau sumber dari pihak lain. Pilihan bahasa dan tema Anda disimpan di browser Anda sendiri. Situs, unduhan, dan diskusi komunitas berada di GitHub (github.com/romyrudiansah/putar), yang bisa mencatat permintaan seperti kunjungan web biasa. Yang Anda tulis di diskusi bersifat publik dan mengikuti kebijakan privasi GitHub.The Putar website doesn't use cookies, analytics, or third-party resources either. Your language and theme choice are stored in your own browser. The website, downloads, and community discussions are hosted on GitHub (github.com/romyrudiansah/putar), which may log requests like any web visit. What you post in the discussions is public and covered by GitHub's privacy policy.
